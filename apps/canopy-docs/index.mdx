Canopy is a privacy-first analytics platform. Track pageviews, custom events, referrers, and countries without cookies, fingerprinting, or third-party requests.

## How it works

1. Add your site in the Canopy dashboard
2. Paste one script tag (or install the Next.js SDK)
3. Events post to your own domain and land in your own Postgres database
4. View live visitors and trends in the dashboard

## Privacy by default

- **No cookies** — sessions are tracked with a random `sessionId` only
- **No fingerprinting** — no localStorage, no device fingerprints
- **DNT aware** — respects the browser Do Not Track signal by default
- **IP hashing** — raw IPs are never stored, only salted hashes
- **First-party** — events post to your own domain, not a third-party tracker
